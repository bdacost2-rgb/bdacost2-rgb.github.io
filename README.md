# Beverley Da Costa — Portfolio

A responsive robotics engineering portfolio built for GitHub Pages. The site lives in [`docs/index.html`](./docs/index.html) and uses no build tools or external dependencies.

## Publish with GitHub Pages

In the repository’s **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch, and set the folder to `/docs`. GitHub Pages will publish the site at the repository’s Pages URL.
